## 批量重命名---rename.py
- 使用方法
`python rename.py 目标文件夹路径 起始文件名(含后缀) [增量]`

- 注意事项
  1. 目标文件夹路径为绝对路径，且内含文件均为同一后缀名
  2. 起始文件名格式  
     [自定义内容(不含'['和']')]+连接符('-'、'\_'或不加连接符)+数字  
     举个例子：  
     `[海贼王]-0001.png`，则程序会把第一个文件重命名成`海贼王0001.png`，
  3. 增量可选，默认为1，后续文件根据前一个文件数字自增。


## 图片压缩工具
批量压缩图片工具  

**快速使用**:
```bash
python compress_img.py ${your_img_dir} --ratio ${压缩率} --out ${输出路径}
```
**参数**:
   - `your_img_dir`: 目标图片文件夹, **必选**
   - `ratio`: 压缩比例（`压缩前的宽/压缩后的宽`）, 可选
   - `out`: 输出图片路径，可选，默认是目标图片文件夹下的`dst`

**help**:
```bash
python compress_img.py --help
```
